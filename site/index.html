ci-example

This site exists to prove the portfolio's CI telemetry and uptime monitoring end to end: it is created from the ulisseas/project-template, built and released by GitHub Actions, exported as traces and metrics on every run, and watched by a synthetic check. It belongs to neillshazly.com.

Public dashboards:

  • Status: uptime, latency and TLS expiry of the deployed sites
  • CI: workflow durations and success rate per repo
  • Releases: what version each repo has deployed and when
